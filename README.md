# **Woofi (Wonderful Of Indonesia)**
Platform digital yang bersifat menarik perhatian serta informatif tentang tempat wisata dan budaya lokal yang berasal dari Indonesia

## Description Proyek

### Apa yang dilakukan aplikasi Anda?
Memberikan sebuah informasi tentang budaya, tradisi, alat musik tradisional, tempat wisata yang bersifat subjektif teruntuk wisatawan lokal maupun internasional

### Mengapa Anda menggunakan teknologi yang Anda gunakan? 
Mengikuti perkembangan teknologi untuk memaksimalkan proyek ini supaya berjalan dengan baik

## Cara Menginstall dan Menjalankan Projek
1. Clone repository untuk menjalankan perintah berikut ini di terminal atau Git Bash Anda:
`https://github.com/CC25-SF061/woofi-frontend.git`
2. Buka Visual Studio Code atau editor kesayangan Anda dan klik "Clone Git Reposotory..." lalu tempelkan salinan anda. Tempat proyek ini di folder Anda.
3. Tunggu proses menganalisi kode oleh Visual Studio Code.
4. Buka terminal dengan cara "Ctrl+Shift+`" atau bisa juga dengan cara arahkan cursor ke panel atas lihat menu "Terminal" klik menu tersebut dan pilih "New Terminal".
5. Ketik `npm install` di terminal tersebut. Setelah itu tekan Enter. Tunggu beberapa saat untuk mendownload package.
6. Setelah selesai ketik lagi pada terminal tersebut `npm run dev` setelah itu tekan Enter. 
7. Tahan tombol Ctrl setelah itu klik "Local:" yang berwarna biru
